# MiruRecetas · Web y PWA

**MiruRecetas** es una aplicación web instalable para consultar recetas, organizar menús semanales, preparar platos, revisar información nutricional y utilizar listas de compra Bring!.

**Abrir MiruRecetas:** https://mirurecetas.github.io/menu-anual-recetas/  
**Dirección corta:** https://mirurecetas.github.io/

## Contenido público

Este repositorio aloja exclusivamente la web/PWA ya generada: páginas HTML, CSS, JavaScript para el navegador, imágenes, iconos, datos públicos necesarios para las funciones de la aplicación y recursos mínimos de compatibilidad con enlaces anteriores.

El código de desarrollo, los generadores, las pruebas, los contratos internos y las fuentes de datos no se mantienen aquí. Las versiones publicadas se generan desde el entorno privado de desarrollo.

El historial Git conserva versiones anteriores del repositorio; la retirada de archivos de la rama actual no elimina ese historial.
